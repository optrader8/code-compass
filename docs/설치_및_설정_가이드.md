# Code Compass 설치 및 설정 가이드

## 시스템 요구 사항

Code Compass를 설치하고 실행하기 위해 다음 시스템 요구 사항이 필요합니다:

### 하드웨어 요구 사항
- **CPU**: 최소 2코어 이상
- **RAM**: 최소 4GB 이상 (대규모 코드베이스 분석 시 8GB 이상 권장)
- **디스크 공간**: 최소 500MB 이상의 여유 공간

### 소프트웨어 요구 사항
- **운영체제**: 
  - Windows 10 이상
  - macOS 10.14 이상
  - Linux (Ubuntu 18.04, CentOS 7 이상)
- **Node.js**: 버전 16 이상
- **npm**: 버전 7 이상 (yarn도 지원)

### 추가 도구
- **ripgrep**: 텍스트 검색을 위해 필요 (>=11.0.0)
  - 설치 방법은 아래 "ripgrep 설치" 항목 참조

## 설치 방법

### npm을 통한 설치 (권장)

1. **Node.js 설치 확인**
   ```bash
   node --version  # v16.0.0 이상이어야 함
   npm --version   # 7.0.0 이상이어야 함
   ```

2. **Code Compass 글로벌 설치**
   ```bash
   npm install -g code-compass
   ```

3. **설치 확인**
   ```bash
   code-compass --version
   ```

### 소스 코드를 통한 설치

1. **저장소 클론**
   ```bash
   git clone https://github.com/optrader/code-compass.git
   cd code-compass
   ```

2. **의존성 설치**
   ```bash
   npm install
   ```

3. **빌드**
   ```bash
   npm run build
   ```

4. **로컬 설치**
   ```bash
   npm link
   ```

## ripgrep 설치

Code Compass는 고속 텍스트 검색을 위해 ripgrep을 사용합니다. 시스템에 설치되어 있지 않다면 다음 지침에 따라 설치하세요:

### Windows
```powershell
# Chocolatey를 사용한 설치
choco install ripgrep

# 또는 Scoop을 사용
scoop install ripgrep
```

### macOS
```bash
# Homebrew를 사용한 설치
brew install ripgrep
```

### Linux (Ubuntu/Debian)
```bash
# apt를 사용한 설치
sudo apt install ripgrep
```

### Linux (CentOS/RHEL/Fedora)
```bash
# dnf를 사용한 설치 (Fedora)
sudo dnf install ripgrep

# 또는 yum을 사용 (CentOS/RHEL)
sudo yum install ripgrep
```

### 설치 확인
```bash
rg --version
# 또는
ripgrep --version
```

## 설정 구성

Code Compass는 다양한 설정을 지원합니다. 설정은 전역, 프로젝트, 명령줄 수준에서 구성할 수 있습니다.

### 전역 설정

전역 설정은 사용자 홈 디렉토리에 `.code-compass.json` 파일을 생성하여 구성합니다:

```bash
# 전역 설정 파일 생성
touch ~/.code-compass.json
```

기본 전역 설정 예시:
```json
{
  "workspace": {
    "excludePatterns": ["node_modules", ".git", "dist", "build", "*.log"],
    "maxFileSize": 104857600,
    "supportedLanguages": ["typescript", "javascript", "python"]
  },
  "lsp": {
    "enabled": true,
    "stdio": true,
    "port": 7777,
    "logLevel": "info"
  },
  "parsers": {
    "parseTimeout": 10000,
    "maxFileSize": 104857600
  },
  "cache": {
    "enabled": true,
    "memoryLimit": 52428800,
    "diskLimit": 524288000,
    "ttl": 3600000
  }
}
```

### 프로젝트 설정

프로젝트 루트 디렉토리에 `.code-compass.json` 파일을 생성하면 프로젝트별 설정이 가능합니다:

```json
{
  "workspace": {
    "excludePatterns": [
      "node_modules", 
      ".git", 
      "dist", 
      "build", 
      "coverage",
      "tests/fixtures"
    ],
    "maxFileSize": 52428800,
    "supportedLanguages": ["typescript", "javascript"]
  },
  "analysis": {
    "complexity": {
      "calculateCyclomatic": true,
      "calculateCognitive": true,
      "calculateMaintainability": true,
      "thresholds": {
        "high": 15,
        "medium": 8,
        "low": 3
      }
    }
  }
}
```

## IDE 통합

Code Compass는 다양한 IDE에서 사용할 수 있도록 LSP(Language Server Protocol)를 지원합니다.

### VSCode 통합

1. **Code Compass CLI 설치 확인**
   ```bash
   code-compass --version
   ```

2. **VSCode 확장 설치**
   - VSCode 마켓플레이스에서 "Code Compass" 확장을 검색 후 설치
   - 또는 수동으로 LSP 클라이언트 확장 설치

3. **VSCode 설정 (settings.json)**
   ```json
   {
     "codeCompass.lsp.enabled": true,
     "codeCompass.lsp.serverPath": "/usr/local/bin/code-compass",
     "codeCompass.features": {
       "hover": true,
       "definition": true,
       "references": true,
       "codeMetrics": true
     }
   }
   ```

### Vim/Neovim 통합

1. **vim-plug를 사용한 설치**
   ```vim
   " init.vim 또는 .vimrc에 추가
   Plug 'autozimu/LanguageClient-neovim', {
     \ 'branch': 'next',
     \ 'do': 'bash install.sh',
     \ }
   ```

2. **LSP 설정**
   ```vim
   let g:LanguageClient_serverCommands = {
     \ 'typescript': ['code-compass', 'lsp', '--stdio'],
     \ 'javascript': ['code-compass', 'lsp', '--stdio'],
     \ 'python': ['code-compass', 'lsp', '--stdio'],
     \ }
   ```

### Emacs 통적

1. **lsp-mode 설치**
   ```elisp
   (use-package lsp-mode
     :ensure t
     :commands lsp)
   ```

2. **LSP 서버 등록**
   ```elisp
   (defun setup-code-compass-lsp ()
     (require 'lsp-mode)
     (lsp-register-client
      (make-lsp-client
       :new-connection (lsp-stdio-connection "code-compass lsp --stdio")
       :activation-fn (lsp-activate-on "typescript" "javascript" "python")
       :server-id 'code-compass)))
   ```

## 환경 설정

### 환경 변수

Code Compass는 다음과 같은 환경 변수를 지원합니다:

```bash
# 캐시 디렉토리 설정
export CODE_COMPASS_CACHE_DIR="/path/to/cache"

# 로그 레벨 설정
export CODE_COMPASS_LOG_LEVEL="debug"

# LSP 서버 포트 설정
export CODE_COMPASS_LSP_PORT="8080"

# 최대 파일 크기 제한 (바이트)
export CODE_COMPASS_MAX_FILE_SIZE="104857600"
```

### 설정 우선순위

Code Compass는 다음 우선순위에 따라 설정을 적용합니다:

1. **명령줄 인자** (가장 높은 우선순위)
2. **환경 변수**
3. **프로젝트 설정 파일** (`.code-compass.json`)
4. **전역 설정 파일** (`~/.code-compass.json`)
5. **기본값** (가장 낮은 우선순위)

## 문제 해결

### 일반적인 설치 문제

#### 1. Node.js 버전 문제
**증상**: `node --version`이 v16 미만을 표시함
**해결**: 최신 Node.js LTS 버전 설치

Ubuntu/Debian:
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
```

macOS:
```bash
brew install node
```

#### 2. 권한 문제
**증상**: `npm install -g` 실행 시 권한 오류
**해결**: npm 구성 변경
```bash
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH=~/.npm-global/bin:$PATH
# 또는 ~/.bashrc 또는 ~/.zshrc에 추가
```

#### 3. ripgrep 미설치 오류
**증상**: `rg` 명령어를 찾을 수 없음
**해결**: 위의 "ripgrep 설치" 항목 참조

#### 4. Tree-sitter 컴파일 오류
**증상**: `npm install` 실행 시 Tree-sitter 컴파일 오류
**해결**: 
- Python 3 설치 확인
- 빌드 도구 설치 (Windows: `npm install --global windows-build-tools`)

### 성능 관련 문제

#### 1. 느린 검색 속도
**가능한 원인**:
- 캐싱이 활성화되지 않음
- 너무 많은 파일을 검색
- 하드웨어 성능 부족

**해결 방법**:
- 캐시 설정 확인
- `excludePatterns`에 불필요한 디렉토리 추가
- `maxFileSize` 설정 조정

#### 2. 메모리 사용량 과다
**가능한 원인**:
- 캐시 크기 제한 미설정
- 대형 파일 포함

**해결 방법**:
- `cache.memoryLimit` 설정
- `maxFileSize` 설정 조정
