# Code Compass 사용자 문서

## 개요

Code Compass는 대규모 코드베이스를 검색하고 분석하기 위한 Node.js 기반의 고급 CLI 도구입니다. 이 도구는 개발자와 LLM 코딩 에이전트가 특정 함수, 클래스, 코드 블록을 빠르게 찾아 풍부한 메타데이터와 함께 추출할 수 있도록 지원합니다.

## 주요 기능

### 1. 빠른 검색
- ripgrep 수준의 성능으로 대규모 코드베이스 탐색
- 텍스트 기반 검색과 AST 기반 구조 검색 모두 지원

### 2. 정확한 범위 지정
- 함수/클래스/블록 단위의 정확한 추출
- Tree-sitter AST 파싱을 통한 정확한 코드 범위 인식

### 3. 풍부한 메타정보
- 파일명, 라인 범위, 코드 컨텍스트 제공
- 코드 복잡도, 의존성, 호출 관계 분석

### 4. LLM 친화적
- LLM 코딩 에이전트가 쉽게 파싱/사용 가능한 출력 포맷
- JSON/Markdown 출력 포맷 지원

### 5. IDE 통합
- LSP(언어 서버 프로토콜) 지원으로 VSCode, Vim, Emacs 등과 통합
- 코드 네비게이션, 심볼 검색, 복잡도 분석 등 제공

## 설치

### 전제 조건
- Node.js 16 이상
- npm 또는 yarn 패키지 매니저

### 설치 방법

```bash
# npm을 사용한 설치
npm install -g code-compass

# 또는 직접 빌드
git clone https://github.com/optrader/code-compass.git
cd code-compass
npm install
npm run build
```

## 사용법

### CLI 사용

#### 기본 검색
```bash
# 텍스트 패턴 검색
code-compass search "function fetchUserData"

# 특정 함수 찾기
code-compass search "fetchUserData" --type function

# 특정 클래스 찾기
code-compass search "UserService" --type class

# 가져오기(imports) 검색
code-compass search "lodash" --type import

# JSON 형식으로 출력
code-compass search "getUser" --json

# 특정 파일 패턴에서 검색
code-compass search "error" --file "src/**/*.ts"
```

#### 코드 분석
```bash
# 파일 분석
code-compass analyze src/user.ts

# 코드 메트릭 표시
code-compass analyze src/user.ts --metrics

# 복잡도 분석
code-compass analyze src/user.ts --complexity

# 의존성 분석
code-compass analyze src/user.ts --dependencies
```

#### LSP 서버 실행
```bash
# stdio를 통한 LSP 서버 시작
code-compass lsp --stdio

# TCP 모드로 LSP 서버 시작 (포트 7777)
code-compass lsp --port 7777
```

### LSP 기능

IDE에서 Code Compass LSP 서버를 사용하면 다음 기능을 사용할 수 있습니다:

#### 호버 정보
- 코드 심볼 위에 호버하면 복잡도 메트릭, 의존성 정보, 사용 통계가 표시됩니다.

#### 정의로 이동
- 심볼을 클릭하면 해당 정의 위치로 이동합니다.

#### 참조 찾기
- 심볼의 모든 참조 위치를 찾습니다.

#### 문서 기호
- 파일의 함수, 클래스, 변수 등 모든 심볼을 트리 구조로 표시합니다.

#### 코드 렌즈
- 함수 옆에 복잡도 지표를 표시합니다.

## 기술 스택

### 핵심 라이브러리
- **검색**: `ripgrep` (노드 래퍼) 또는 `@vscode/ripgrep`
- **AST 파싱**: 
  - JavaScript/TypeScript: `tree-sitter` + `tree-sitter-typescript`
  - Python: `tree-sitter` + `tree-sitter-python`
  - 기타 언어: `tree-sitter` 바인딩
- **LSP 프로토콜**: `vscode-languageserver`
- **CLI 프레임워크**: `commander`
- **출력 포맷**: `chalk`, `cli-table3`, `ora`

### 성능 최적화
- Glob 패턴: `fast-glob`
- 병렬 처리: `p-queue`
- 캐싱: 파일 해시 기반 AST 캐시 (`lru-cache`)
- 인덱싱: 선택적으로 `.code-compass-cache` 생성

## 사용 사례

### 개발자 사용 사례
```bash
# 특정 함수가 어디에 정의되어 있는지 찾기
code-compass search "createUser" --type function

# 특정 파일의 모든 export된 함수 나열
code-compass search "export" --file "src/api/users.ts"

# 특정 클래스를 사용하는 모든 위치 찾기
code-compass search "UserService" --type class

# 에러 처리 패턴 검색
code-compass search "try.*catch" --regex --context 5
```

### LLM 에이전트 사용 사례
```bash
# JSON 형식으로 함수 추출 (LLM이 파싱하기 쉬움)
code-compass search "getUserById" --type function --json

# 특정 영역만 추출하여 컨텍스트 제공
code-compass analyze "src/user.ts:45-67" --format markdown

# 시맨틱 검색 (벡터 임베딩 활용)
code-compass search "database connection logic" --type semantic
```

## 확장 가능성

### 플러그인 시스템
Code Compass는 플러그인 시스템을 통해 사용자 정의 분석기와 언어 지원을 추가할 수 있습니다. 플러그인을 개발하여 다음과 같은 기능을 확장할 수 있습니다:

- 사용자 정의 분석기
- 추가 언어 파서
- 사용자 정의 쿼리 유형
- 사용자 정의 출력 포맷

### API 통합
Code Compass는 프로그래밍 방식으로 사용할 수 있도록 API를 제공합니다. Node.js 응용 프로그램에서 직접 코드 분석을 수행할 수 있습니다:

```typescript
import { CoreEngine } from 'code-compass/core/engine';
import { ASTParser } from 'code-compass/parsers/registry';
import { CacheSystem } from 'code-compass/utils/cache';

const cache = new CacheSystem();
const parser = new ASTParser(cache);
const analyzer = new CodeAnalyzer(cache);
const engine = new CoreEngine(parser, analyzer, cache);

// 검색 수행
const results = await engine.search({
  pattern: 'myFunction',
  type: 'function',
  options: { contextLines: 3 }
});
```

## 문제 해결

### 일반적인 문제 및 해결 방법

#### 1. LSP 서버가 응답하지 않음
- 서버 로그 확인: `code-compass lsp --stdio --log-level debug`
- 포트 충돌 확인: 다른 응용 프로그램이 동일한 포트를 사용하지 않도록 확인

#### 2. 검색 속도가 느림
- 캐시 설정 확인: 메모리 제한을 늘려보세요
- 파일 크기 제한 확인: 너무 큰 파일을 제외하도록 구성

#### 3. 특정 언어 지원 오류
- 설치된 Tree-sitter 그램 확인
- 지원 언어 목록 확인 및 업데이트
