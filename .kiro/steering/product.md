# Product Overview

## What is Code Search CLI?

A Node.js-based CLI tool for codebase search and analysis that helps developers and LLM coding agents quickly find and extract specific functions, classes, and code blocks with rich metadata.

## Core Value Proposition

- **Fast Search**: ripgrep-level performance for large codebases
- **Precise Extraction**: AST-based accurate function/class boundary detection
- **Rich Metadata**: File paths, line ranges, complexity metrics, dependencies
- **Agent-Friendly**: JSON/Markdown output formats optimized for LLM consumption
- **Progressive Enhancement**: REPL → CLI → Agent Integration

## Target Users

1. **Developers**: Interactive code exploration and navigation
2. **LLM Coding Agents**: Automated code analysis and context extraction
3. **DevOps Teams**: Code quality analysis and documentation generation

## Key Differentiators

- Combines text search speed with structural code understanding
- Unified interface for multiple programming languages
- Designed specifically for AI agent integration
- REPL-first approach for exploratory workflows
